# Quy chuẩn Quản lý Mã nguồn (Git Conventions)

> **QUY TẮC BẮT BUỘC CHO AI:** Mọi nội dung Commit Code phải tuân thủ nghiêm ngặt chuẩn Conventional Commits.

## 1. Định dạng Commit
Cấu trúc bắt buộc: `<type>: <mô tả ngắn gọn bằng tiếng Việt hoặc tiếng Anh>`

## 2. Các tiền tố (Types) được phép sử dụng:
- `feat:` Khi thêm một tính năng mới hoàn toàn.
- `fix:` Khi sửa một lỗi/bug.
- `refactor:` Khi tối ưu hóa, viết gọn lại code cũ mà không làm thay đổi logic.
- `docs:` Khi chỉ thay đổi tài liệu, README, rules.md.
- `chore:` Khi cập nhật thư viện, file cấu hình (như pom.xml, package.json).
